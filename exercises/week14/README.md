# Capstone

One graded exercise -- a small Library/Book system with JSON persistence, synthesizing dict/list/dataclass-style records, dunders (__len__, __contains__), and the json module from earlier weeks. pandas/requests/opencv/FastAPI usage is bonus scope for your own capstone idea on top of this, not required here -- see the week's project-shaped schedule (kickoff, build, build, polish, demo).

## Exercises

Each exercise below lives in its own folder with its own `solution.py` (the entry point) and `README.md` (the problem statement). Work through them in order.

- **`exercise01/`** -- records, dunders, and JSON persistence tying the course together
